How to setup a vagrant server: Install Virtual Box and vagrant
In a directory, lets say project/, create through the git bash a Vagrantfile, as seen on this directory example
on the bash:
    vagrant up
    ...
    ...
    vagrant ssh


Now you are logged in the server. (vagrant@ubuntu-bionic:~)
You can:
    vagrant halt
    vagrant destroy
    exit

To create a v-env in the vagrant server, do:
    cd /vagrant/
and then: (vagrant@ubuntu-bionic:/vagrant$)
    source ~/env/bin/activate

Now you are in e Virtual environment

To start a DJANGO REST project, on (env)vagrant@ubuntu-bionic:/vagrant$:
    django-admin.py startproject profiles_project .
, which means:  django-admin.py -- Execute the script of creation
                startproject -- Execute
                profiles_project -- Name of new folder to be created, with new files in it created
                . -- Dot means create the project at the ROOT of our current directory
Then:
    python manage.py startapp profiles_api
